Bitácora, tareas y supervisión de operarios

Guía de implementación Plot Lab — lado operario (anotador flotante) y lado admin/gerencia (panel de actividades + legajo RRHH).

Actualizado 26 ago 2026 · Commits df0c241 + 496df23 · Producción: plotcenterlab.com.ar

Resumen

Cada operario registra en un botón flotante (bitácora, checklist, anotador) lo que hace en el día, con título de tarea, horario y adjuntos. Admin y gerencia ven todo en /actividades-operarios con calendario, estadísticas, modal de detalle y enlace al legajo del empleado.

1. Lado operario — Anotador flotante (FAB)

Dónde aparece

Panel externo Plot Design (/operario-externo/diseno), vista operario interna, tablero principal (BoardPage) y admin Plot Design cuando el usuario es operario asignado.

1.1 Botón flotante

Esquina inferior derecha. Icono de cuaderno; al abrirlo muestra el panel «Tareas y anotador».

1.2 Tres pestañas

PestañaUsoDatos que guarda
BitácoraRegistro de trabajo hecho en un job/OPDetalle, título, job, OP/venta, horario, adjuntos (PDF, imágenes, etc.)
ChecklistTareas pendientes del díaTítulo (= texto de la tarea), marcable como hecho, horario opcional
AnotadorNotas libresTexto + horario opcional, sin obligación de OP

1.3 Formulario de alta (composer)

1.4 Lista del día

Debajo del formulario solo se listan entradas de hoy (zona horaria Argentina), con contador «Hoy · N entradas».

Permisos operario

Solo puede anotar en un job si es el asignado (o el job está disponible para tomarlo). Los adjuntos solo se permiten en entradas tipo bitacora.

4.3 Flujo de datos (resumen)

  1. Operario completa FAB → Storage (adjuntos) + RPC crear → fila en work_pool_operario_notas.
  2. Si es bitácora con job → evento en work_pool_job_events tipo nota.
  3. Admin abre supervisión → RPC con fecha del calendario → tarjetas + stats.
  4. Clic en entrada → modal; «Ver legajo» → VerLegajoModal pestaña Actividades Plot.

5. Capturas incluidas y cómo regenerarlas

Listo

Las 10 capturas (01-fab-boton.png … 10-legajo-tab.png) están en docs/img/bitacora-operarios/ y se muestran arriba en este documento.

Regenerar
  1. npm run dev y en otra terminal npm run docs:bitacora-capturas (UI real de la app en local).
  2. Producción con datos vivos: DOC_STAFF_USER, DOC_STAFF_PASS, BASE_URL=https://www.plotcenterlab.com.ar y node scripts/capture-bitacora-screenshots.mjs --live.
  3. PDF: Imprimir → Guardar como PDF (gráficos de fondo activados).
