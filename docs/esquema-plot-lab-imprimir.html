Qué es Plot Lab

Sistema interno de Plot Center para operar la fábrica de comunicación visual: órdenes de producción (OP), ventas, caja, stock, RRHH, chat y canales públicos (tótem, portal cliente, embed WordPress).
Repo: plotrello Prod: trello.plotcenter.com.ar API: Vercel /api DB: Supabase

Hoja 4 · Flujos cruzados y atajos
A · Producción clásica Lead/Brief → Asesor/Presupuesto → OP Tablero → Sectores → Mostrador/Entrega → Caja/ERP
B · Comercio digital /cliente (pedido) → /clientes-web (admin) → Convertir a OP → Tablero → producción
C · Trabajo externo phi o postulación → /operario-externo → Plot Design o Bolsa Plot → tareas de OP
D · Chat público WordPress iframe → /embed/chat → conversación → leads CRM / Atención público
E · Asistencia tablet-reloj / biométrico → asistencia → RRHH horarios · novedades · liquidación HE
F · Tótem Autogestión / consulta / asesor → impresión o cola → backoffice impresoras
