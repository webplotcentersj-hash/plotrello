1. Stack de la aplicación

CapaTecnología
FrontendReact 19, TypeScript, Vite 7
RoutingReact Router v7

2. Entradas de la aplicación

  • index.html → App principal (tablero, mostrador, compras, RRHH, CRM, etc.).
  • admin.html → App admin (dashboard y reportes).
  • tablet-firma.html → App tablet para firma de entrega.

3. Estructura de src/

  • main.tsx, App.tsx — Entrada y rutas.
  • components/ — Board, TaskCard, Header, Login, NotificationsDropdown, ChatAI, PlotAI, modales, etc.
  • pages/ — BoardPage, MostradorDashboardPage, CRMVentasPage, ComprasDashboardPage, RecursosHumanos*, Cliente*, etc.
  • services/ — api.ts (Supabase + RPC), supabaseClient.ts, plotAIService.ts, plotAIContextService.ts.
  • hooks/ — useAuth, useApiData, useClienteAuth.
  • types/ — api.ts, board.ts, pedidos.ts.
  • utils/ — sectorPermissions.ts, dataMappers.ts, dateUtils.ts, exportUtils.ts.
  • admin/ — App admin (admin.html).
  • tablet-firma/ — App tablet firma.
